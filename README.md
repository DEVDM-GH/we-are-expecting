# We Are Expecting 🍼

A magical storybook + countdown locket pregnancy reveal — Dev & Priti are expecting!

Built with **Vite + React + Tailwind CSS**, deployed on Vercel.

---

## Features

- 📖 **Storybook** — 5-page story with CSS 3D page-flip animation
- 🔒 **Countdown Locket** — golden locket that opens with a hinge animation
- 🎉 **Confetti burst** — fires on locket open via `canvas-confetti`
- ⏳ **Live countdown** — dynamically calculates days until February 2027
- 📱 **Fully responsive** — works beautifully on mobile and desktop
- ✨ **Animated star background** — soft twinkling particles in brand colors

---

## Local Setup

```bash
# Install dependencies
npm install

# Start dev server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## Build for Production

```bash
npm run build
```

Output is in the `dist/` folder.

---

## Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import the `we-are-expecting` repository
4. Vercel auto-detects Vite — click **Deploy**
5. Your site is live at `*.vercel.app` 🎉
